# Todo List App

A full-stack Todo List web application built with Python Flask and SQLite.

## Tech Stack
- Frontend: HTML, CSS, Jinja2
- Backend: Python + Flask
- Database: SQLite

## Features
- Add new tasks
- Mark tasks as complete or undo
- Delete tasks
- Live stats - Total, Done, Pending
- REST API endpoint /api/todos

## How to Run
pip install -r requirements.txt
python app.py
Open browser: http://127.0.0.1:5000
